    How this works
    • One simulated minute per tick, 8:00 to 22:00. Orders arrive until 18:00 and are promised within 4 hours.
    • The manufacturer preps each order, then hands it to a carrier. Fixed zones sends north-street orders to A and south-street orders to B. Balance load reroutes around an offline carrier and evens out queues.
    • Trucks carry up to 8 orders and leave when full or when the oldest order has waited 25 minutes.
    • On-time rate counts every order that is due; at the end of the day, undelivered orders count as missed.
    • Simulation: js/sim.js, pure and seeded, so the same choices always give the same day. No DOM, no WebGL.
    • Tests: tests/sim.test.js, 15 tests (npm test). They include "an unanswered outage misses the goal", "rerouting alone helps but is not enough" and "trucks sent to the offline carrier are wasted".
    • Renderer: three.js reads the simulation's state each frame and never changes it.
    • Illustrative model, scaled from ~200 clients to 24. Not TAG Chemical's data or software.

      The order engine

      In 20 seconds: the same 100 orders, about 15 of them urgent, processed two ways. A FIFO queue serves them in arrival order; a priority queue (a binary heap) always serves the most urgent first. Watch which one makes urgent orders late.

      data structures · coursework idea

      Orders arrive faster than they can be processed (each takes 25% longer than the average gap between arrivals), so a queue always builds and the order you serve them in matters. Squares in processing order. Filled = urgent (crimson if late), outlined crimson = a regular order that ran late. My inventory project used these structures in Python; this JavaScript version runs here so you can try it.

      // push: add at the next open slot, then rise only past less urgent orders · O(log n)
push(x) {
  const a = this.a; a.push(x);
  let i = a.length - 1;
  while (i > 0) {
    const p = (i - 1) >> 1;
    if (!this.less(a[i], a[p])) break;
    [a[i], a[p]] = [a[p], a[i]]; i = p;
  }
}
